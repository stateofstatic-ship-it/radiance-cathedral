The Confessional

  • Quick mode is BetterBench's own "smoke check, not a publishable result": 5 passes per category and one run per engine, deployed engine first.
  • The pre-registered rule called for confidence intervals that betterbench run never prints, so the formal verdict is "not separated". The individual runs don't overlap (code: 88–95 vs 141–200 t/s).
  • Engine and model format changed together, so this compares the two packages.
  • Radiance's --tp-wire wht6 link between the cards is lossy above 25 rows, which covers prefill and batched decode. Single-stream decode is exact. It also keeps a 47.68 GiB n-gram table in pinned RAM.
  • Answer quality has not been tested yet. That is the next session.
